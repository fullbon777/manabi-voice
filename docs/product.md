# Product

## Name

Manabi Voice

## Concept

Manabi Voice is a web app for deepening understanding through spoken or written explanation.

Users explain what they learned in their own words after class, reading, work, or daily discoveries. The app inspects that explanation and responds with the right kind of intervention for the user's current understanding.

The app does not simply summarize. It checks whether the user's explanation is clear, sufficient, and factually safe, then helps the user notice and repair gaps.

## Core value

The app helps users deepen understanding by combining:

- the user's own explanation
- an inspection of unclear wording, insufficient explanations, small mistakes, and claims that may need fact checking
- confirmation questions when the user should think before receiving the answer
- detailed explanations when correction or reinforcement is needed
- review questions that help the user revisit the learning later

## Intervention model

The app changes its response based on the inspected understanding state.

- Major misunderstanding: explain before asking confirmation questions. The app gently points out the misunderstanding, gives the correct explanation, and leaves review questions.
- Mostly correct with gaps: ask confirmation questions first, then provide correct answers and a detailed explanation of today's scope. This is the main experience.
- Well understood: avoid forced questioning. Offer extension questions, review questions, or a path to complete today's log.
- Uncertain: avoid overclaiming. Ask for more context or mark the explanation as needing cautious follow-up.
