# Requirements

## Functional requirements

- Users can create a learning log.
- Users can view today's learning logs.
- Users can view logs by date.
- Users can view a log detail page.
- The app can run in mock mode without external API keys.
- The app stores logs locally using SQLite.
- The analysis structure supports unclear wording, insufficient explanations, claims, and check questions.

## Non-functional requirements

- Must stay free-tier friendly.
- Must work locally.
- Must not require paid APIs for initial development.
- Must keep API keys out of Git.
- Must provide `.env.example`.
